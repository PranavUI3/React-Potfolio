# Pranav Sharma — Developer Portfolio

A modern, responsive developer portfolio built with **React** and **Tailwind CSS**.

The portfolio showcases my skills, projects, learning journey, and ways to connect with me.

## 🚀 Features

* Responsive design for desktop, tablet, and mobile
* Modern dark-themed UI
* React component-based architecture
* Tailwind CSS styling
* Featured projects section
* Skills and technologies section
* About section
* Contact section
* Smooth navigation between sections
* Interactive hover and transition effects

## ⚙️ Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate into the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available on the local development server provided by Vite.
